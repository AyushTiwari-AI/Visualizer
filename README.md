# Data Analysis & Visualization Program

A Python-based program for performing data analysis and visualization using **Pandas** and **Matplotlib**.

## Features

1. Load Dataset
2. Explore Data
3. Perform DataFrame Operations
4. Handle Missing Data
5. Generate Descriptive Statistics
6. Data Visualization
7. Save Visualization
8. Exit

## Data Exploration

The program allows you to:

* Display the first 5 rows
* Display the last 5 rows
* Display column names
* Display data types
* Display basic information

## DataFrame Operations

The program provides options to:

* Sort by column
* Filter rows by condition
* Select specific columns
* Group by column and aggregate
* Rename columns
* Drop a column

## Missing Data Handling

You can:

* Display rows with missing values
* Fill missing numeric values with the mean
* Drop rows with missing values
* Replace missing values with a specific value

## Descriptive Statistics

The program generates descriptive statistics using:

`df.describe(include="all")`

## Data Visualization

The program supports:

* Bar Plot
* Line Plot
* Scatter Plot
* Pie Chart
* Histogram
* Stack Plot

## Save Visualization

Generated visualizations can be saved by providing a file name, for example:

`scatter_plot.png`

## Technologies Used

* Python
* Pandas
* Matplotlib

## How to Run

1. Open `_Visualizer.ipynb` in Jupyter Notebook.
2. Run the program.
3. Enter the path of your CSV dataset.
4. Select the required option from the menu.
5. Follow the instructions displayed by the program.
